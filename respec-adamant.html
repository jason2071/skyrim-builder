Nordic Souls 3.2.2 · Adamant 6.0.4

How to respec

Back to Adamant builder

Apply your Adamant build

  1. Make a backup save. This preset includes Hand to Hand, Security, Ascension, and enabled Nordic Souls perk patches; it is not standalone Adamant.
  2. Plan your perks, then check each plugin prefix against the Mod Index in MO2’s Plugins tab. Enter light-plugin indices without the colon: FE:0B0 becomes FE0B0. The defaults reflect the profile used to extract this data; changing your load order can change these indices.
  3. Use Export reset and Export addperks to download reset.txt and addperks.txt.
  4. Put both files beside the SkyrimSE.exe launched by your modlist. Nordic Souls uses its Game Root folder. NGVO typically uses Stock Game. Check MO2’s executable configuration for the actual path; the Steam installation may be a different copy.
  5. Launch your modlist through MO2, load your save, open the console with ~, and run bat reset, followed by bat addperks. Verify the resulting perks before saving.

Reset removes only visible perks represented in this preset, including all their ranks. It leaves hidden passive perks alone and does not uninstall a perk overhaul. Addperks sets selected skills to the planned requirements, which can lower an existing higher skill. Neither script changes character level or refunds unspent perk points.

วิธีใช้กับ Nordic Souls

  1. สำรองเซฟก่อน แล้วเลือก Perk ในหน้า Adamant ชุดข้อมูลนี้รวม Hand to Hand, Security, Ascension และแพตช์ Perk ที่เปิดใช้ใน Nordic Souls 3.2.2
  2. ตรวจเลข Mod Index ของปลั๊กอินในแท็บ Plugins ของ MO2 ให้ตรงกับช่องในหน้าเว็บ เช่น FE:0B0 ให้กรอก FE0B0 หากเปลี่ยน load order เลขนี้อาจเปลี่ยนตาม
  3. ส่งออก reset.txt และ addperks.txt แล้ววางข้าง SkyrimSE.exe ที่ MO2 ใช้เปิดเกม สำหรับ Nordic Souls ให้ตรวจโฟลเดอร์ Game Root ส่วน NGVO มักใช้ Stock Game
  4. เข้าเกมผ่าน MO2 โหลดเซฟ เปิด Console แล้วพิมพ์ bat reset ตามด้วย bat addperks ตรวจ Perk ที่ได้ก่อนบันทึกเซฟ

ไฟล์ reset ลบเฉพาะ Perk ที่ปรากฏในชุดข้อมูลนี้ ไม่ลบ Perk แฝง ไม่คืนแต้ม และไม่ใช้แทนการถอนม็อด ส่วน addperks ตั้งค่าสกิลที่เลือกให้เท่ากับระดับที่ build ต้องการ จึงอาจลดสกิลเดิมที่มีระดับสูงกว่า ทั้งสองไฟล์ไม่เปลี่ยนเลเวลตัวละคร
