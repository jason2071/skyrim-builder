Skyrim Perk Builder

คู่มือการ Respec

วางแผนและนำ Perk build ไปใช้ในเกมอย่างปลอดภัย

Read this guide in English →

เครื่องมือนี้ช่วยวางแผน Perk สำหรับตัวละคร และสร้างไฟล์คำสั่ง Console เพื่อปรับตัวละครในเกมตาม build ที่เลือก

การวางแผน Build

  • คลิกซ้ายที่ Perk เพื่อเพิ่มระดับ และคลิกขวาเพื่อลดระดับ
  • คลิกสายสกิลด้านซ้ายเพื่อเปิดดู Perk ในสายนั้น
  • เลือกภาษา description เป็น English หรือ ไทย จากแถบด้านล่าง
  • กด Clear all เมื่อต้องการล้าง Perk ที่เลือกทั้งหมด

นำ Build ไปใช้ในเกม

ขั้นตอนนี้ใช้ได้กับ Skyrim เวอร์ชัน PC ที่เปิด Console ได้เท่านั้น

  1. สำรองไฟล์เซฟก่อนเสมอ โดยทั่วไปอยู่ที่ C:\Users\<ชื่อผู้ใช้>\Documents\My Games\Skyrim\Saves\
  2. กด Export reset และ Export addperks แล้วบันทึกเป็น reset.txt และ addperks.txt ในโฟลเดอร์เกม เช่น <Steam>\steamapps\common\Skyrim\
  3. เปิดเซฟที่ต้องการในเกม กด ~ เพื่อเปิด Console แล้วพิมพ์ bat reset กด Enter จากนั้นพิมพ์ bat addperks แล้วกด Enter

ข้อควรรู้

คำเตือน: reset.txt จะล้าง Perk เดิมทั้งหมด ก่อนให้ addperks.txt ใส่ Perk ตาม build ใหม่ การใช้คำสั่ง Console อาจกระทบเซฟ ม็อด หรือ achievements จึงควรสำรองเซฟก่อนทุกครั้ง

สคริปต์ปรับเลเวลและ Perk ที่จำเป็น แต่ไม่ปรับค่า Health, Magicka หรือ Stamina หากต้องการปรับเอง ใช้คำสั่ง เช่น player.setav health 500
