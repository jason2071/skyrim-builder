Use this tool to plan a character build and generate Console-command scripts for applying its perks in game.

Planning a build

  • Left-click a perk to add a rank; right-click it to remove one.
  • Select a skill tree on the left to view its perks.
  • Choose English or Thai perk descriptions from the toolbar.
  • Use Clear all to remove every selected perk.

Applying your build in game

These steps require a PC version of Skyrim with the Console enabled.

  1. Back up your saves first. They are commonly stored in C:\Users\<username>\Documents\My Games\Skyrim\Saves\.
  2. Use Export reset and Export addperks. Save the downloads as reset.txt and addperks.txt in the game directory, for example <Steam>\steamapps\common\Skyrim\.
  3. Load the target save, press ~ to open the Console, then run bat reset. Press Enter, then run bat addperks.

Important notes

Warning: reset.txt removes existing perks before addperks.txt applies the planned build. Console use can affect saves, mods, and achievements, so always keep a backup.

The scripts set the required level and perks, but do not change Health, Magicka, or Stamina. Use a Console command such as player.setav health 500 if needed.
